## Архитектура и Технологии

Проект создавался с упором на **чистую, масштабируемую архитектуру** и независимость данных от движка Unity.

* **Паттерн MVC (Model-View-Controller):** Полное разделение логики и визуала. GridModel - это чистый C#-класс (массив 3х3), который ничего не знает о Canvas. GridView отвечает только за анимации.
* **Service Locator / Dependency Injection:** Связи внедряются через конструкторы. Экономика игры (WalletService) передается Контроллерам через стартовый Bootstrapper. FindObjectOfType полностью отсутствуют.
* **Data-Driven Design:** Баланс юнитов, стоимости призыва и награды вынесены в ScriptableObjects. Геймдизайнер может настраивать игру без вмешательства в код.
* **Data Transfer Object (DTO):** Состояние доски (армия) может быть запаковано в независимую структуру ArmyPackage для бесшовной передачи данных в другие сцены.
* **SOLID Принципы:** Логика открыта для расширения (например, добавление механики "Жертвоприношения" не потребовало изменений в логике "Слияния" или "Модели Сетки").

## Unit-Тестирование
Бизнес-логика экономики полностью отвязана от MonoBehaviour и вынесена в отдельные сборки (Assembly Definitions).
Это позволило покрыть сервис кошелька **Юнит-тестами** в режиме EditMode, обеспечив надежность транзакций (покупки юнитов, начисление душ).

## Визуальный фидбек
* Плавные UI-анимации, всплывающий Floating Text и динамическое масштабирование объектов написаны на DOTween.
* Сетка интерфейса собрана адаптивно (Canvas Scaler, Anchors, Grid Layout), UI не ломается на мобильных или ультрашироких экранах.
* Кастомные шрифты(TextMeshPro) и нарезка спрайтов по принципу 9-Slice для достижения стилистики Dark Fantasy.

## Как запустить проект локально
1. Клонируйте репозиторий.
2. Откройте в Unity.
3. Откройте сцену Scenes/InitScene.
4. Нажмите Play. 
*(В инспекторе можно менять цены юнитов в папке _Scripts/CreaturesSO)*
